# 已知限制

> 本文件是 LyCAD 文档的一部分，入口见仓库根目录的 [README](../README.md)。

| 限制 | 说明 |
|---|---|
| 圆/圆弧在非等比缩放下被近似 | 椭圆已是**独立的图元类型**（ELLIPSE 的读写、绘制、捕捉、属性面板都支持），但圆的变换仍按等效均匀缩放处理，不会自动转成椭圆。等比缩放与镜像下为精确结果。 |
| 出图固定比例超出纸面即分页 | 适应图纸恒为一页；固定比例（1:1 / 自定义）下图纸超出可打印区时按先行后列自动分页，预览与打印页数一致。不做「缩到一页」与拼页顺序之外的打印样式（页边裁切线、页码标注等）。 |
| 块参照的几何不可直接编辑 | 支持块定义 + `INSERT` 的完整往返、显示、拾取、捕捉、属性面板与 分解(EXPLODE)。但**没有块编辑器**（不能双击进块改内容），也没有 `BLOCK`/`INSERT`/`WBLOCK` 命令（不能新建块或再插入），`MINSERT` 的阵列在变换后会被烘焙展开。要改块内容先 `EXPLODE` 打散；非等比拉伸落到块参照上时几何同样被烘焙进一份匿名块定义副本，该处不再是引用（几何精确）。 |
| 未实现逆向编辑 | 不支持 OFFSET / TRIM / EXTEND / FILLET / CHAMFER / STRETCH。刻意保留为未实现状态而非半成品。 |
| 未建模的实体类型 | 角度标注、公差与引线标注、多线（MLINE）、面（3DFACE）、图像与视口。导入时按类型计数跳过并明确告知，不静默丢弃。 |
| DWG 表格本体的 cells 数组未写出 | 表格在 DXF 与 DWG 里都按原生 ACAD_TABLE 实体读写。DWG 的单元格数据体（cells 数组）位编码未完全逆向，本体里暂不写出单元格；几何与文字完整保留在 `*Tnn` 匿名几何块中，读取端按格归位补回文字、反推合并区，读回内容不缺失。DXF 无此环节：单元格文字与合并区域直接随本体往返。两条链路的差异由 `test_table` 盯住。 |
| 含换行的单元格文字**不能存成 DXF** | 单元格文字可以含换行（同格多行在 DWG 读入时按 `*Tnn` 几何块归位、用 `\n` 拼接；双击编辑也能增删行）。**DWG 侧不受影响**（TV 串带长度前缀），几何块也不受影响（每行一个 TEXT）；但 DXF 的原生 ACAD_TABLE 把单元格文字写进 1 组码，而 DXF 是行式格式、1 组码的值不能跨行，于是文件被写坏：实测把一个单元格改成含换行后，原 10 个非空单元格读回只剩 5 个（`test_table` 的 DXF 两档同时红）。修法是写出时按 `\P` 转义（内置库写 MTEXT 段落就是这么做的）、读入时再转回，两侧必须一起改才往返相等——涉及导入文件的显示语义，故未擅自改动。 |
| 单元格字高与字体**不解析本体记录，只认配对几何块** | 字高与字体是逐格的，且**本体（ACAD_TABLE 记录）既不带字高也不带单元格字体**，落点是配对的 `*Tnn` 几何块（块内每条 TEXT 的字高与样式名）。因此：别人写出的文件若**没有**那个几何块（或块里没有该格的文字），字高只能按该行行高的一半估一个（`assignMissingCellHeights`），字体则退回默认——此时原生 ACAD_TABLE 里可能记着的逐格字高就被丢掉了（内置库的 `DRW_Table::Cell` 没建模这两项，要读得先扩它）。反过来，本程序写出的文件里这两项完整保留，往返不掉。 |
| 弧长标注的**符号**按固定形状绘制 | 尺寸弧中点处的弧长符号（小半圆）半径取 0.933 倍字高、两端内缩一个箭头长，比例实测自 AutoCAD 图纸的匿名几何块 `*D4`；文字方向取尺寸弧中点的切线。这些量本应由 DIMSTYLE 决定，本程序不解析 DIMSTYLE（见上一行），因此只保证与实测样本一致。 |
| 文字有两种图元：TEXT 与 MTEXT | **TEXT**（`TextEntity`）：支持镜像生成标志（71 bit2/bit4，PCB 背面丝印即此表达）与宽度因子（41，含负值=镜像）；内容里的换行会被保留（画布按多行绘制、双击编辑框按多行打开、导出到 R2000 及以上时写回为 MTEXT）。**MTEXT**（`MTextEntity`）：内容按**原始字符串**保存，`\P` 段落、`\f` 内联字体与其余格式码一字不改地往返；附着点、参考栏宽（41）、书写方向（72）、行距样式与系数（73/44）、挤出方向（210）、样式名（7）逐字段保留；画布按附着点九宫格定位、**按内容里的 `\P` 分行绘制**（不依据参考栏宽重新折行，与 AutoCAD/浩辰一致），双击编辑框按段落显示（回车确认 / Alt+Enter 换行，段落自动与 `\P` 互转）。**尚未支持**：内联格式码的逐段渲染（`\H` 字高、`\C` 颜色、`\S` 堆叠、制表位等只做剥码显示，文件里仍是原样）、分栏（75/76/78/79/48/49）、背景填充（90/45/63/441）、字符范围（42/43）——这三组是 R2007+ 的字段，内置库的 `DRW_MText` 尚未建模，往返会丢；界面上也没有「新建 MTEXT」命令（可用 TEXT 输入后在编辑框里换行，导出时即为 MTEXT）。文字样式（`STYLE` 表）随文件往返：图元带样式名（7），字体（3/4 组码与记录 TrueType 字体的 ACAD 扩展数据）存在文档的文字样式表里按名解析，导出原样写回；只有界面上的样式管理（新建/改名/删除）尚未提供。 |
| 标注样式固定 | 测量文字字高固定 3.5（读入时不解析 DIMSTYLE），无标注样式管理器；箭头/文字位置由定义点推导，不支持用户自定义箭头形态。 |
| 填充为单环边界 | 支持直线与凸度圆弧混合的单个外部环（含「2 顶点 + 凸度 1」整圆焊盘）；多环嵌套与样条边界取第一个可解析环。 |
| EDA 图层配色为启发式 | 文件自带颜色时严格按文件显示；仅当 EDA 导出的 DXF 缺失图层颜色时，才按图层名关键词套用行业惯例配色（顶/底丝印分色：顶黄/底绿，与常见 EDA 2D 视图一致），可在图层面板修改，导出时随图层表写出。 |
| 线型为内置标准集 | 支持 CONTINUOUS / DASHED / DASHDOT / DASHDOTDOT / DOT / HIDDEN / CENTER / PHANTOM / BORDER；文件中引用的自定义线型会回退为 CONTINUOUS。 |
| 单图纸空间 | 无布局/视口体系，仅在模型空间工作；图纸空间里的实体也会被一并导入到模型空间。 |
| 不支持对象编组 | 未建模；文件里的 `GROUP` 对象在读取时按对象跳过。 |
| 功能区宽度靠滚动而非折叠 | 面板排开的总宽度大于窗口，窗口偏窄时出现横向滚动条。AutoCAD 的做法是把放不下的面板折叠成一个按钮，本项目未实现该机制——滚动不会隐藏任何功能，只是需要多一次拖动。 |
| 图标为自绘，非 AutoCAD 原图标 | 形态按 AutoCAD 的表达习惯绘制（夹点、箭头、虚线辅助线），但不复制其美术资源。 |
