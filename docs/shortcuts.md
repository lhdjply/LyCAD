# 快捷键

> 本文件是 LyCAD 文档的一部分，入口见仓库根目录的 [README](../README.md)。

| 按键 | 功能 | 按键 | 功能 |
|---|---|---|---|
| `Esc` | 取消当前命令 | `F1` | 命令列表 |
| `空格` / `回车` | 重复上一命令 | `F3` | 对象捕捉开关 |
| `Delete` | 删除选中对象 | `F7` | 网格显示开关 |
| `Ctrl+A` | 全选 | `F8` | 正交模式开关 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 | `F9` | 栅格吸附开关 |
| `中键拖拽` | 平移视图 | `F10` | 极轴追踪开关 |
| `滚轮` | 缩放视图（以光标为锚点） | `左→右框选` | 窗选（完全包含） |
| `Tab`（命令行） | 命令补全 | `右→左框选` | 交叉选（接触到） |
| `↑` / `↓`（命令行） | 历史回溯 | `双击文字` | 编辑文字内容 |
| `Ctrl+W` | 关闭标签页 | `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个标签页 |
| `Enter`（编辑框内） | 确认 | `Alt+Enter`（编辑框内） | 换行 |
